# E-commerce Website

A Django e-commerce web application where users can browse products, add them to a cart and place orders.

## Features
- User accounts (register and login)
- Product listing
- Shopping cart
- Order placement

## Tech Stack
- Python
- Django
- SQLite
- HTML, CSS

## Project Structure
- `accounts` - user registration and login
- `products` - product catalogue
- `cart` - shopping cart
- `orders` - order management
- `store` - main project settings and URLs
- `templates` - HTML pages

## How to Run
1. Clone this repository
2. Create a virtual environment and activate it
3. Install Django: `pip install django`
4. Apply migrations: `python manage.py migrate`
5. Start the server: `python manage.py runserver`
6. Open `http://127.0.0.1:8000/` in your browser
